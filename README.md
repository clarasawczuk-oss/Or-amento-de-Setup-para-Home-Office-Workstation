# Orçamento de Setup Home Office &amp; Workstation  Aplicação web responsiva que apresenta uma tabela de custos detalhada e um gráfico interativo de distribuição de despesas. O projeto foi construído com base na estrutura de tabelas categorizadas com quantidade e preço unitário, expandindo o escopo para um setup completo de trabalho.
